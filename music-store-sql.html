Project overview

This project uses SQL to analyze a digital music store's sales database (customers, invoices, tracks, genres, and employees) to find out what actually drives revenue — without pulling the data into Excel or Python first.

Business problem

Store managers need to know which genres, artists, and countries generate the most revenue, and which customers and sales staff are the top performers — all directly from the database, using SQL.

Business questions

  • Which genres and artists generate the highest revenue?
  • Which countries have the highest total sales?
  • Which employees (sales support agents) have the highest customer sales?
  • Which customers have the highest lifetime spend?
  • What is the average invoice value by country?
